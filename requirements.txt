# Mọi provider thật (openai / openrouter) đều dùng OpenAI Python SDK — OpenRouter
# chỉ khác base_url. Yêu cầu >=1.40 vì agent dùng:
#   - response_format={"type": "json_schema", ...} (strict JSON schema)
#   - tool_calls streaming-style multi-turn loop (xem agent/core.py)
openai>=1.40

# Lưu ý cố ý:
# - KHÔNG thêm python-dotenv: agent/config.py tự parse .env (xem _load_dotenv_if_present).
# - KHÔNG thêm anthropic SDK: provider anthropic hiện là stub-only và đã được
#   VALID_PROVIDERS công nhận, nhưng không có code path thật. Sẽ thêm
#   `anthropic>=0.30` khi provider được nối.
# - KHÔNG khoá phiên bản chính xác để `pip install -U` an toàn; CI/dev pin
#   trong requirements-dev.txt (tách riêng khi cần).
